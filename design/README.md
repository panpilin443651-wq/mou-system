# ไฟล์ดีไซน์อ้างอิง

วางรูปที่เอ็กซ์พอร์ตจาก Figma ไว้ในโฟลเดอร์นี้ แล้วบอก Claude ว่าวางแล้ว

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `login.png` | ดีไซน์หน้าเข้าสู่ระบบ |

**วิธีเอ็กซ์พอร์ตจาก Figma**

1. คลิกเลือกเฟรมของหน้า login (คลิกที่ชื่อเฟรมด้านบนซ้ายของกรอบ ให้ขอบเป็นสีฟ้าทั้งเฟรม)
2. แถบขวาล่างสุด หัวข้อ **Export** กด **+**
3. เลือก **2x** และ **PNG** แล้วกด **Export**
4. เซฟลงโฟลเดอร์นี้ ตั้งชื่อว่า `login.png`

ถ้ามีหน้าอื่นด้วยก็เอ็กซ์พอร์ตมาได้เลย ตั้งชื่อตามหน้าที่มันเป็น
